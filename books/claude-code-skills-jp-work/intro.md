## この本で解決したいこと

Claude Code に事務作業を頼むと、だいたいうまくいきます。ただ、細かいところで毎回同じ指摘が必要です。

- 請求書を頼んだら、**登録番号**や**税率ごとの消費税額**が抜けていた
- 敬語メールを頼んだら、「**おっしゃられる**」のような二重敬語が混ざっていた
- 日報を頼んだら、作業の羅列になって**結論**がどこにも書かれていなかった

そのたびに「インボイス制度では6つの記載事項が必要で……」「消費税の端数処理は税率ごとに1回で……」と説明し直すのは、正直つらい作業です。

この本では、こうした**毎回の説明をスキルにして、Claude に最初から守らせる**方法を解説します。

## スキルとは

Claude Code の「スキル」は、特定の作業のための手順書とツールをひとまとめにしたものです。実体はフォルダで、中には次のものが入ります。

- `SKILL.md`：いつ使うか（description）と、どう進めるか（手順・ルール）を書いたファイル
- 必要に応じて、計算やチェックを確実に行う**スクリプト**や、テンプレートなどの参考資料

Claude は依頼内容に合うスキルを自分で選んで読み込み、その手順に従って作業します。プロンプトに毎回長い説明を書く必要がなくなり、計算のように「LLM に任せると時々間違える部分」はスクリプトに任せられます。

https://github.com/ayukari/jp-backoffice-skills

後半では、そのスキル集の設計・テスト・評価と改善の過程を、コードと数字つきで説明します。自分の会社やチームの業務に合わせたスキルを作りたい方向けの内容です。

## 想定している読者

- Claude Code を使い始めた、またはこれから使う方
- 請求書・メール・稟議・日報など、日本語の事務作業を AI に任せたい方
- 社内向けに「うちのやり方」を AI に覚えさせたい方

プログラミングの経験は、前半では不要です。後半のスクリプトの章では Python を使いますが、コードは全文を載せています。

## この本の書き方について

この本は、著者が Claude Code の支援を受けて執筆し、内容を確認したうえで公開しています。掲載しているコマンドとコードは実際に動作を確認したもので、テスト件数や評価結果などの数字はスキル集のリポジトリで実際に計測した値です。

税務・法務に関わる内容（インボイス制度など）は、執筆時点の制度にもとづく一般的な説明です。個別の判断は、税理士などの専門家や国税庁の公式情報で確認してください。
